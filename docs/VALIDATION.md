# Verification

All results reported in the SoftwareX manuscript are regenerated by

```bash
python -m pip install -e '.[test]'
python examples/verification.py --output figures/verification
```

which writes figures (PNG/PDF), CSV tables and `summary.json` (with software
versions and platform). The full script takes about 12 s on one CPU core.
The key checks are also enforced by the test suite (`python -m pytest -q`,
21 tests), which runs on Python 3.10–3.13 in GitHub Actions.

| Check | Reference | Result (v0.3.0) |
|---|---|---|
| Critical Mach number | 1 − exp(M²/2) + M² = 0 | M_c = 1.5852010652 |

## Known limitations

- Sagdeev profiles are truncated where φ falls to 10⁻⁵ φ_m (the far field is a
  saddle point of the spatial ODE); beyond that point they are set to zero.
- The KdV solver is periodic; the domain must contain the soliton tails.
- The mass is conserved to round-off; the L² norm and Hamiltonian are not
  conserved exactly by IF-RK4, but their drift is reported.
- Only positive-polarity solitons of the cold-ion/Boltzmann-electron model are
  implemented.
