# SoftwareX manuscript

- `main.tex` — manuscript source (Elsevier `elsarticle`, SoftwareX Original
  Software Publication structure: code metadata C1–C9, sections 1–5,
  CRediT, declarations).
- `main.pdf` — compiled manuscript.
- `elsarticle.cls` — Elsevier class, built from the official
  STM-Document-Engineering/elsarticle sources (LPPL), included so the
  manuscript builds anywhere.
- Figures come from `../figures/verification/`, generated by
  `python examples/verification.py --output figures/verification`.

Build: `latexmk -pdf main.tex` (or `pdflatex main.tex` twice).
