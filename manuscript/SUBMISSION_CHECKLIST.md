# SoftwareX submission checklist

- [x] Manuscript in Elsevier `elsarticle` with SoftwareX OSP structure
- [x] Code metadata table C1–C9
- [x] Body under 3000 words (~2500 incl. captions), 5 figures (limit 6)
- [x] All figures and numbers reproduced by `examples/verification.py`
- [x] 21 automated tests; CI on Python 3.10–3.13
- [x] References checked; DOIs added where available
- [x] CRediT, competing-interest and generative-AI declarations
- [ ] Upload files to https://github.com/alvarohumberto/PlasmaWaveLab and confirm CI is green
- [ ] Create release `v0.3.0` on GitHub
- [ ] (Recommended) Connect the repo to Zenodo before the release to get a DOI; add it to C2 and CITATION.cff
- [ ] Review the generative-AI declaration and acknowledgements wording
- [ ] Submit via Editorial Manager; SoftwareX will also mirror the code to its own GitHub organisation
